// 装饰性 Line 示例 - 使用 Line 系统
// 可用按键 ID，音符数，指令数，总时长
0,1,2,3
4
16
20.000

// 按键初始位置 (key_name x y show)
0 -3 -8 1
1 -1 -8 1
2 1 -8 1
3 3 -8 1

// 谱面
// #：记分音符首次出现
// !：不计分音符首次出现
// %：非音符首次出现
// $：按键指令
(note num command time_a time_b x1 y1 x2 y2 (.json file or hold_duration))

// ========================================
// Line 定义区域
// ========================================
// Line 格式：Line index start_time end_time [note_indices]
// 会自动为指定时间范围内的音符添加 spin 和 shift 装饰效果

// Line 1: 螺旋上升效果（音符 1-4）
Line 1 5.000 15.000 1 2 3 4

// ========================================
// 基础音符定义（Line 会自动应用装饰）
// ========================================

# hold 1 drop_to 0 5.000 15.000 -3 -8 -3 8 10
# hold 2 drop_to 1 5.000 15.000 -1 -8 -1 8 10
# hold 3 drop_to 0 5.000 15.000 1 -8 1 8 10
# hold 4 drop_to 0 5.000 15.000 3 -8 3 8 10

// ========================================
// 按键装饰效果
// ========================================
$ key 0 shift 5.000 15.000 -3 -8 -3 -5
$ key 1 shift 5.000 15.000 -1 -8 -1 -5
$ key 2 shift 5.000 15.000 1 -8 1 -5
$ key 3 shift 5.000 15.000 3 -8 3 -5
