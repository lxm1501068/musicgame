## 一、谱面文件格式

### 基本结构
```
// 轨道按键信息（可用按键 ID，音符数，指令数，总时长）
0,1,2,3
6
11
28.000

// 按键初始位置 (key_name x y show)
0 5 -5 1
1 4 -4 1
2 3 -3 1
3 2 -2 1

// 谱面
// #：记分音符首次出现
// !：不计分音符首次出现
// %：非音符首次出现
// $：按键指令
(note num command time_a time_b x1 y1 x2 y2 (.json file or hold_duration))
```

### 符号说明
- `#` - 记分音符的首次出现
- `!` - 不计分音符的首次出现
- `%` - 同一音符的非首次出现（后续指令）
- `$` - 按键指令标记

## 二、音符指令

### 1. destroy 指令

**功能：** 在指定时间销毁音符

**格式：**
```
# tap 1 destroy 16.000
```

**参数：**
- `num`: 音符序号
- `time_a`: 销毁时间

**示例：**
```
% tap 2 destroy 16.000    // 在第 16 秒时销毁音符 2
```

**适用音符类型：** 所有音符类型

---

### 2. shift 指令

**功能：** 让音符从起始位置线性移动到目标位置

**格式：**
```
# tap 2 shift 14.000 16.000 4 -4 5 -5
```

**参数：**
- `num`: 音符序号
- `time_a`: 开始时间
- `time_b`: 结束时间
- `x1`: 起始 X 坐标
- `y1`: 起始 Y 坐标
- `x2`: 目标 X 坐标
- `y2`: 目标 Y 坐标

**示例：**
```
! tap 2 shift 14.000 16.000 4 -4 5 -5
// 音符 2 从第 14 秒到第 16 秒，从 (4, -4) 移动到 (5, -5)
```

**适用音符类型：** 所有音符类型

**注意事项：**
- 移动速度 = 距离 / (timeB - timeA)
- 可以与其他指令组合使用

---

### 3. move 指令

**功能：** 按照预设的 JSON 路径文件移动音符

**格式：**
```
# tap 3 move 14.000 16.000 move_1.json
```

**参数：**
- `num`: 音符序号
- `time_a`: 开始时间
- `time_b`: 结束时间
- `json_filename`: JSON 路径文件名（位于 StreamingAssets 目录）

**JSON 文件格式示例：**
```json
{
  "frames": [
    {"time": 14.0, "x": 4.0, "y": -4.0},
    {"time": 15.0, "x": 4.5, "y": -4.5},
    {"time": 16.0, "x": 5.0, "y": -5.0}
  ]
}
```

**示例：**
```
# tap 3 move 14.000 16.000 move_1    // 或使用 move_1.json
# flick 6 move 20.000 22.000 path_move
```

**适用音符类型：** 所有音符类型

**注意事项：**
- JSON 文件必须放在 StreamingAssets 目录
- 文件扩展名可以是 `.json` 或不带扩展名
- 路径点会按时间自动插值

---

### 4. drop_to 指令

**功能：** 音符从起始位置下落到目标位置，并绑定到指定按键

**格式：**
```
# tap 1 drop_to 0 14.000 16.000 4 -4 5 -5
# hold 4 drop_to 1 18.000 20.000 4 -4 5 -5 3
```

**参数：**
- `num`: 音符序号
- `key_name`: 绑定的按键 ID
- `time_a`: 开始时间
- `time_b`: 结束时间（判定时间）
- `x1`: 起始 X 坐标
- `y1`: 起始 Y 坐标
- `x2`: 目标 X 坐标
- `y2`: 目标 Y 坐标
- `hold_duration`: （仅 Hold/MTap）按住持续时间

**示例：**
```
# tap 1 drop_to 0 14.000 16.000 4 -4 5 -5
// Tap 音符 1 绑定到按键 0，从 14 秒到 16 秒从 (4,-4) 下落到 (5,-5)

# hold 4 drop_to 1 18.000 20.000 4 -4 5 -5 3
// Hold 音符 4 绑定到按键 1，下落 2 秒，需要按住 3 秒

# dtap 5 drop_to 0 20.000 22.000 4 -4 5 -5
// DTap 音符 5 绑定到按键 0
```

**适用音符类型：** Tap, Hold, DTap, MTap, Flick

**注意事项：**
- Hold 和 MTap 音符需要额外的 `hold_duration` 参数
- timeB 是判定时间点
- 下落完成后音符会固定在目标位置

---

### 5. spin 指令 ⭐

**功能：** 让音符在指定时间内旋转指定的角度

**格式：**
```
# hold 1 spin 10.000 12.000 0 45
```

**参数：**
- `num`: 音符序号
- `time_a`: 开始旋转时间
- `time_b`: 结束旋转时间
- `init_direction`: 初始方向角度（度）
  - 0° = 向右
  - 90° = 向上
  - 180° = 向左
  - 270° = 向下
- `degree_per_second`: 每秒旋转度数（度/秒）
  - 正值 = 逆时针旋转
  - 负值 = 顺时针旋转

**示例：**
```
# hold 1 spin 10.000 12.000 0 45
// 从 10 秒到 12 秒，从 0 度开始，每秒逆时针旋转 45 度
// 总旋转角度 = 45 * 2 = 90 度

# hold 2 spin 15.000 18.000 90 -60
// 从 15 秒到 18 秒，从 90 度开始，每秒顺时针旋转 60 度
// 总旋转角度 = -60 * 3 = -180 度

# hold 3 drop_to 0 20.000 22.000 0 0 5 5 3
# hold 3 spin 20.000 22.000 0 90
// 组合使用：音符在移动的同时逆时针旋转 180 度
```

**适用音符类型：** 所有音符类型（主要用于 Hold）

**注意事项：**
- 可以与其他移动指令同时使用
- 多个 spin 指令的效果会累加
- 旋转完成后保持在最终角度

## 三、按键指令

### 1. hide 指令

**功能：** 在指定时间隐藏按键

**格式：**
```
$ key 0 hide 24.000
```

**参数：**
- `keyIndex`: 按键 ID
- `time`: 隐藏时间

**示例：**
```
$ key 0 hide 24.000    // 在第 24 秒隐藏按键 0
```

---

### 2. show 指令

**功能：** 在指定时间显示按键

**格式：**
```
$ key 0 show 26.000
```

**参数：**
- `keyIndex`: 按键 ID
- `time`: 显示时间

**示例：**
```
$ key 0 show 26.000    // 在第 26 秒显示按键 0
```

---

### 3. shift 指令（按键）

**功能：** 让按键从起始位置线性移动到目标位置

**格式：**
```
$ key 1 shift 24.000 26.000 4 -4 3 -3
```

**参数：**
- `keyIndex`: 按键 ID
- `time_a`: 开始时间
- `time_b`: 结束时间
- `x1`: 起始 X 坐标
- `y1`: 起始 Y 坐标
- `x2`: 目标 X 坐标
- `y2`: 目标 Y 坐标

**示例：**
```
$ key 1 shift 24.000 26.000 4 -4 3 -3
// 按键 1 从 24 秒到 26 秒，从 (4,-4) 移动到 (3,-3)
```

---

### 4. move 指令（按键）

**功能：** 按照预设的 JSON 路径文件移动按键

**格式：**
```
$ key 2 move 26.000 28.000 move_2.json
```

**参数：**
- `keyIndex`: 按键 ID
- `time_a`: 开始时间
- `time_b`: 结束时间
- `json_filename`: JSON 路径文件名

**示例：**
```
$ key 2 move 26.000 28.000 move_2
// 按键 2 按照 move_2.json 的路径移动
```

## 四、音符类型

### 支持的音符类型

| 类型 | 说明 | 英文标识 |
|------|------|----------|
| Tap | 单点音符 | tap |
| Hold | 长按音符 | hold |
| DTap | 双击音符 | dtap |
| MTap | 多击音符 | mtap |
| Flick | 滑动音符 | flick |
| Drag | 拖动音符 | drag |

### 音符特性对比

| 音符类型 | 需要 DropTo | 需要 Hold | 特殊要求 |
|---------|------------|-----------|----------|
| Tap | ✅ | ❌ | 基础音符 |
| Hold | ✅ | ✅ | 需要 hold_duration |
| DTap | ✅ | ❌ | 两次点击 |
| MTap | ✅ | ✅ | 需要 hold_duration(点击次数) |
| Flick | ✅ | ❌ | 简单格式 |
| Drag | ✅ | ❌ | 拖动判定 |

## 五、组合指令示例

### 示例 1：移动 + 旋转
```
# hold 1 drop_to 0 10.000 12.000 0 0 5 5 2
# hold 1 shift 10.000 12.000 0 0 5 5
# hold 1 spin 10.000 12.000 0 90
// 音符从 (0,0) 移动到 (5,5)，同时逆时针旋转 90 度
```

### 示例 2：复杂路径移动
```
# tap 1 drop_to 0 20.000 22.000 0 0 10 10
# tap 1 move 20.000 22.000 complex_path
// 音符按照 JSON 文件定义的复杂路径移动
```

### 示例 3：按键移动 + 隐藏
```
$ key 0 shift 30.000 32.000 5 -5 6 -6
$ key 0 hide 35.000
$ key 0 show 40.000
// 按键先移动，然后隐藏，最后重新显示
```

## 六、编辑器中的使用

### 添加音符指令
1. 在 CreateScene 中选择音符
2. 切换到"添加"模式
3. 选择指令类型（shift/move/destroy/drop_to/spin）
4. 按提示输入参数
5. 点击确认

### 添加按键指令
1. 在 CreateScene 中选择按键
2. 切换到"添加"模式
3. 选择指令类型（shift/move/hide/show）
4. 按提示输入参数
5. 点击确认

### 删除指令
1. 切换到"删除"模式
2. 在下拉列表中选择要删除的指令
3. 点击"删除选中指令"

## 七、常见问题

### Q1: 如何让音符边移动边旋转？
**A:** 同时添加 shift/move 指令和 spin 指令即可。

### Q2: spin 指令的角度单位是什么？
**A:** 使用角度制（度），360 度为一圈。

### Q3: move 指令的 JSON 文件放在哪里？
**A:** 放在 Unity 项目的 StreamingAssets 目录下。

### Q4: 如何让 Hold 音符在按住期间旋转？
**A:** 在 drop_to 的同时添加 spin 指令，旋转会在整个 hold 期间持续。

### Q5: 多个指令会冲突吗？
**A:** 不会，不同类型的指令会叠加效果（如移动 + 旋转）。

{
    public bool is_show;          // 是否显示
